# 配色・背景・ロゴの設定

[README に戻る](../README.md)

設定画面は「外観 → Clear Layers の設定」（`/admin/appearance/settings/clear_layers`）です。

## 初期設定

`config/install/clear_layers.settings.yml` に保存した初期値を、新規インストール時に使います。

| 設定 | 初期値 |
| --- | --- |
| 配色 | 青 × シアン（オーシャンブルー） |
| 透過率 | 40% |
| ぼかし | 12px |
| 奥行き | 標準 |
| 左右余白 | 12px |
| ブロック間隔 | 24px |
| 背景 | 同梱の青い背景画像 |
| 標準ロゴ | 背景画像に合わせて５色から自動選択 |
| 明暗モード | 訪問者の OS 設定 |

既存サイトの保存済み設定は、テーマの更新だけでは上書きしません。テーマ設定のプレビューは初期状態では閉じており、クリックで展開します。保存済み設定と現在のトップページを表示します。

「サイト全体の配色」では、次の組み合わせを選べます。各配色にライト／ダークの定義があり、パネル・文字・リンク・ボタン・フォーム・フッターに共通で適用します。背景画像は別の設定なので、基調色に合う画像を「ページの背景画像」で選択してください。

| 基調色 | 組み合わせ |
| --- | --- |
| 青 | 青 × シアン、淡い青 × アクア、青・藍 × ラベンダー、青緑 × ミント |
| 緑 | 緑 × ミント、深緑 × 青緑 |
| 赤 | 赤 × ローズ、赤 × コーラル |
| 琥珀色 | 琥珀色 × ゴールド、琥珀色 × オレンジ |
| モノクロ | モノクロ × シルバー、モノクロ × チャコール |

背景画像は、テーマ設定の「ページの背景画像」から「同梱の背景画像から選択」を開き、サムネイル一覧の「選択」を押して指定します。青・緑・赤・琥珀色・モノクロの背景を `background/` に同梱しています。「テーマ標準の背景に戻す」で青い背景に戻せます。選択はプレビューに反映され、設定フォームを保存するとサイト全体に適用されます。メディアへの登録や追加モジュールは不要です。

`background/` 直下に PNG・JPEG・WebP・AVIF・GIF の画像を追加すると、テーマ設定の選択候補に表示されます。設定にはファイル名を保存するので、選択済み画像の名前や配置を変える場合は、テーマ設定で選び直してください。以前のメディア背景設定は、同梱画像を選んで保存するか標準背景に戻して保存するまで維持します。

### v1.1.0 への更新

テーマのファイルを更新した後、Drupal プロジェクト直下で `vendor/bin/drush cr` を実行してください。テーマの再インストールや設定の一括インポートは不要です。

テーマ設定の「サイト全体の配色」と「ページの背景画像」で、配色と画像をそれぞれ選んで保存します。既存の青系配色の設定 ID は維持しているため、更新だけで選択済みの配色が変わることはありません。メディアから新しい背景を選択する機能は、同梱画像の選択に置き換わります。以前のメディア背景は表示を継続し、同梱画像を選ぶか標準背景に戻して保存した際に切り替わります。

## 標準ロゴの色

標準サイトロゴは、形と透過背景をそろえた青・緑・赤・琥珀色・モノクロの５種類を `images/branding/logo-*.svg` に同梱しています。

テーマ設定（`/admin/appearance/settings/clear_layers`）の「サイトロゴ」で「テーマ標準のロゴを使用する」をオンにすると、「標準ロゴの色」を選べます。各色に明るい背景・暗い背景での見本を表示します。

- **背景画像に合わせて自動選択（初期値）**：同梱の青・緑・赤・琥珀色・モノクロの背景画像に対応するロゴを表示します。背景を変更して保存すると、ロゴも追従します。
- **５色から手動選択**：背景画像に関係なく、選択した色を表示します。

自動選択でテーマ標準の背景を使う場合、対応する同梱背景が見つからない場合、独自に追加した背景や以前のメディア背景を使う場合は、青いロゴになります。その場合も手動で色を選べます。ライト／ダークモードと訪問者の切り替えに応じて、ダーク時はロゴを明るく調整します。

Drupal のサイトブランディングブロックと、Canvas に配置した同じブロックに共通で適用します。ブロック側でロゴを非表示にした場合は表示しません。「ロゴ・サイト名（手入力）」SDC に直接指定した画像 URL は、その指定を維持します。

既存サイトで色の設定が未保存の場合も自動選択を使います。テーマの更新後は `vendor/bin/drush cr` でキャッシュを再構築してください。設定の一括インポートは不要です。独自ロゴを使っているサイトでは、「テーマ標準のロゴを使用する」をオンにして保存すると切り替わります。新規インストールでは標準ロゴと自動選択を有効にします。

## 自鯖ロゴ

背景透過の「自鯖」ロゴを `images/branding/jisaba-life-logo-v2.png` に同梱しています。使う場合は、テーマ設定（`/admin/appearance/settings/clear_layers`）のロゴ画像でデフォルト画像の使用をオフにし、画像パスを `themes/custom/clear_layers/images/branding/jisaba-life-logo-v2.png` に設定します。

このロゴはライトモードでは元の青・紺・緑で、ダークモードでは CSS フィルターによって白く表示します。透明部分は維持し、OS の設定とサイトの表示切り替えに連動します。他のファイル名のロゴにはこのフィルターを適用しません。

ロゴだけを表示する場合は、ブランディングブロックの「サイトのロゴ」を有効にし、「サイト名」を無効にします。Canvas の共通ヘッダーを使っている場合は、そのパターン内のブランディングブロックで設定してください。既存サイトのロゴ設定や共通パターンは、テーマ更新だけでは変更しません。

ロゴとサイト名を同時に表示する場合は、テーマ設定の「Settings」内にある「ロゴと文字の配置」で「ロゴの右に文字を表示」または「ロゴの下に文字を表示」を選択して保存します。サイト名とスローガンに共通で適用し、Canvas の共通ヘッダーにも反映します。初期値は「右」です。狭い画面でも選択した配置を維持し、横並びの長い文字は文字の領域内で折り返します。

## 背景画像の制作経緯

元の標準背景画像 `images/backgrounds/waves-blue.png` は、Drupal をイメージし、ChatGPT の画像生成機能を使用して作成しました。色別の選択用画像は `background/` に同梱し、標準には `background/blue-glowing-waves.png` を使います。Drupal の公式提供画像ではありません。

テーマ一覧と README の紹介画像には `images/theme-preview-five-colors.png` を使います。同梱の５色の背景を参照し、内蔵の画像生成ツールで「青を最前面に、緑・赤・琥珀色・モノクロの波模様を５枚のパネルとして重ね、文字を入れずに５色の選択肢を示す」という指示で制作しました。
