# Clear Layers v1.1.5

この文書は、v1.1.5以前の旧バージョン（v1.1.5）のリリース記録です。v1.2.0の新規導入は [README](../../README.md)、v1.1.5以前からの更新は [更新専用の手順](../upgrade-from-v1.1.5.md)を参照してください。

小さい画面で長いコードに合わせて案内ページの本文パネルが画面外へ広がり、コードブロック内で横スクロールできなくなる問題を修正しました。

## 変更内容

- 案内ページ SDC（`clear_layers:information-page`）の幅を親要素の100%に指定し、余白と枠線をその幅に含めるようにしました。
- 長いコードがあっても本文パネルが画面内に収まり、コードブロック内で横スクロールできます。
- 幅768px以上で選択できる75%幅の表示は維持します。SCSS と配布用 CSS を更新しました。

## 更新方法

テーマのファイルを更新し、Drupal プロジェクト直下で実行してください。

```sh
vendor/bin/drush cr
```

## 検証

- 修正前は幅375pxの画面で本文パネルが約545pxまで広がり、コードブロック内で横スクロールできないことをブラウザーで再現しました。
- キャッシュ再構築後の実ページを320・375・390・640・767・768・1024・1440pxの8サイズで確認し、ページが横にはみ出さないことを確認しました。
- スマホ幅で5個すべてのコードブロックが横スクロールすることを確認しました。
- SCSS のコンパイル結果と配布用 CSS の一致（書式差を除く）、差分の空白エラーがないことを確認しました。
