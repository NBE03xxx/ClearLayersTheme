# Clear Layers v1.1.0

テーマ設定で5色の同梱背景をサムネイルから選択できるようにし、サイト全体の配色を12種類に増やしました。新しいサイトでも、背景画像をメディアに登録せずに使えます。

## 変更内容

- `background/` に青・緑・赤・琥珀色・モノクロの5枚を同梱。色と模様がわかる英語のファイル名に統一しました。
- 「ページの背景画像」を、同梱画像のサムネイルから選ぶ方式に変更。選択後のプレビューと、標準の青い背景に戻す操作を追加しました。
- `background/` 直下に追加した PNG・JPEG・WebP・AVIF・GIF も選択候補として表示します。画像形式の変換は行いません。
- 緑・赤・琥珀色・モノクロに各2種類の配色を追加。既存の青系4種類と合わせて12種類とし、基調色がわかる名称にしました。
- 各配色にライト／ダークの色を定義。パネル・文字・リンク・ボタン・フォーム・フッターに共通で適用します。
- README、導入用データの説明、移行ガイド、テーマ・npm パッケージのバージョン表記を更新しました。

## 適用方法と既存設定

テーマのファイルを更新し、Drupal プロジェクト直下で `vendor/bin/drush cr` を実行してください。テーマの再インストール、設定の一括インポート、追加モジュールは不要です。

テーマ設定の「サイト全体の配色」と「ページの背景画像」で、それぞれ選択して保存します。配色を変えても背景画像は自動では切り替わりません。

既存の青系配色の設定 ID と保存済み設定は維持します。メディアから新しい背景を選ぶ機能は同梱画像の選択に置き換わりますが、以前のメディア背景は表示を継続します。同梱画像を選ぶか標準背景に戻して保存すると、新しい背景設定へ切り替わります。

同梱背景はファイル名で保存するため、選択済み画像の名前や配置を変更した場合は、テーマ設定で選び直してください。選択した画像が見つからない場合は標準背景を表示します。

操作と色の組み合わせは [README](https://github.com/NBE03xxx/ClearLayersTheme/blob/v1.1.0/README.md#初期設定) を参照してください。

## 検証

- 同梱5枚の検出、Form API を通した選択・標準背景への復帰、プレビュー、公開 HTML の背景 URL、設定のキャッシュ依存を確認。
- 保存前の余白入力の保持、不正な画像パスの拒否、画像欠落時の標準背景への復帰、以前のメディア設定の保持を確認。診断によってサイト設定を保存しないことも確認。
- サムネイル一覧を Chromium の画面幅1280・390pxで確認。
- 12種類の配色の選択肢・設定スキーマ・ライト／ダークの CSS 出力を確認。
- Chromium で12種類の配色と OS・手動の明暗指定の72通りを検証。文字・リンク・ボタンに適切な色が反映されることを確認。
- 各配色の不透明なパネル・フッターの基本色に対する文字・補助文字・リンクのコントラスト比を確認。最小は約4.90:1です。半透明パネルの実際の見え方は、背景画像と透過率にも依存します。
- 利用者による背景選択と追加配色の動作確認が完了。
