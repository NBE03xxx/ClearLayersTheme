# Clear Layers v1.2.2

[README に戻る](../../README.md)

## Gin Login のログイン画面の修正

Canvas のサイト共通レイアウトが Gin Login の画面を上書きし、公開用のヘッダー・フッターがスタイルのない状態で表示される問題を修正しました。ログイン・パスワード再設定画面で、Gin Login 本来のフォーム配置・見出し・背景画像が表示されます。

- 同梱の Clear Layers Canvas Taxonomy が、Clear Layers を既定テーマとして使うサイトで、別の管理テーマを使用中の場合に Canvas のページ描画を Core の通常描画へ戻します。
- 公開ページ、記事・検索・分類の共通レイアウトと、Canvas の編集プレビューを保持します。
- Core・Canvas・Gin・Gin Login のファイルは変更しません。Gin Login はテーマの新たな必須依存ではありません。
- 既存の設定・コンテンツ・Canvas の下書きは変更しません。

## v1.2.0 / v1.2.1 からの更新

テーマファイルを v1.2.2 に更新します。Git で `main` を追跡している場合は、テーマディレクトリで `git pull --ff-only origin main` を実行します。

同梱の **Clear Layers Canvas Taxonomy** が有効なサイトでは、Drupal プロジェクト直下でキャッシュを再構築すると反映されます。

```sh
vendor/bin/drush cr
```

補助モジュールが未有効のサイトでこの補正を利用する場合は、Canvas と Taxonomy が導入済みであることを確認し、次を実行します。モジュールを有効化しますが、初期構成ボタンの再実行やページテンプレートの作り直しは不要です。

```sh
vendor/bin/drush en clear_layers_canvas_taxonomy -y
vendor/bin/drush cr
```

Gin Login のロゴ・背景設定は保持されます。設定の移行、コンテンツの移行、依存パッケージの追加、CSS・JavaScript の再ビルドは不要です。v1.1.5以前から更新する場合は、先に [更新専用の手順](../upgrade-from-v1.1.5.md)を確認してください。

## 検証範囲

Drupal 11.4.11 / Canvas 1.12.0 のサイトで、次を確認しました。

- Chromium の PC 幅（1440px）・スマートフォン幅（390px）で、ログインとパスワード再設定画面が正常に表示され、横にはみ出さないこと。
- PC で設定済み背景画像が表示され、スマートフォンでは Gin Login 標準の動作に従って非表示になること。
- パスワードの表示・非表示を切り替えられること。認証やフォーム送信は行っていません。
- ログイン画面の見出し・メインフォーム・スキップリンクと、公開用 Canvas 部品が混入しないこと。
- Home・記事・固定ページ・検索・分類ページの応答と、共通ヘッダー・フッターが各1つであること。RSS は HTML の外枠を含まないこと。
- Canvas の共通レイアウト編集プレビューで、内部の部品に選択用の情報があること。
- 読み取り検証の前後で、保存済み設定と Canvas の下書きが変わらないこと。

実行コマンドと前提条件は [開発と検証](../development.md)を参照してください。
