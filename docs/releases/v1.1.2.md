# Clear Layers v1.1.2

ロゴとサイト名を同時に表示するとき、文字の位置を「ロゴの右」「ロゴの下」から選べるようにしました。標準 SVG ロゴを単独で表示できない問題も修正しました。

## 変更内容

- テーマ設定の「Settings」に「ロゴと文字の配置」を追加。サイト名とスローガンの位置を選択でき、Canvas の共通ヘッダーにも適用します。初期値は「右」です。
- 横並びでは、ロゴ用の広い固定配置幅と自動折り返しを見直し、狭い画面でもロゴと文字を横に並べます。長い文字は文字の領域内で折り返します。「下」を選択した場合は、狭い画面でも縦並びを維持します。
- 標準 `logo.svg` に画像の基準サイズ `512×512` を明記。サイト名を非表示にしてロゴだけを表示したとき、表示サイズがなくなる問題を修正しました。表示には引き続き CSS の幅・高さの上限を適用します。
- 移行ガイドと README に、Home 本文内に残ったヘッダー・フッターの整理方法を追記。通常は Site Default を利用でき、既存の部品を編集できない場合は一時的に「サイト共通レイアウト」を明示して整理する手順を案内します。

## 更新方法

テーマのファイルを更新し、Drupal プロジェクト直下で実行してください。

```sh
vendor/bin/drush cr
```

テーマの再インストールや設定の一括インポートは不要です。配置を未設定の場合は初期値の「右」を使います。「下」を使う場合は、`/admin/appearance/settings/clear_layers` の「Settings」→「ロゴと文字の配置」で選択し、保存してください。すでに保存した配置設定は保持します。

ロゴ・サイト名・スローガンを表示するかどうかは、ブランディングブロックで設定します。Canvas では共通ヘッダーのパターン内にあるブロックを編集してください。
