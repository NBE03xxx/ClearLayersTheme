# Clear Layers v1.0.3

記事本文の箇条書きで行頭の記号が表示されない問題を修正しました。通常の段落をインデントするために必要な拡張モジュールと、その導入手順も README に記載しました。

## 変更内容

- クラスのない本文リストに、箇条書きの丸い記号と番号付きリストの数字を明示的に設定。
- 記号を本文の外側に配置し、論理方向の余白を確保。長い項目が折り返しても本文の行頭が揃います。
- CKEditor 5 用の CSS にも同じ表示修正を反映。
- README に CKEditor IndentBlock の追加・有効化、ツールバー設定、許可する HTML の案内を追加。

## 適用方法

テーマを更新し、`vendor/bin/drush cr` でキャッシュを再構築してください。

**通常の文章・段落のインデントには、CKEditor IndentBlock 拡張モジュールの追加・有効化が必要です。** テーマの更新だけでは段落インデントは有効になりません。モジュールは既存のインデント・解除ボタンを利用し、表示用 CSS も提供します。テーマ自体の必須依存には追加していません。

導入手順は [README](https://github.com/NBE03xxx/ClearLayersTheme/blob/v1.0.3/README.md#記事編集画面で段落をインデントする場合) を参照してください。

## 検証

- Chromium の画面幅 1440・390px で、公開ページの箇条書きの記号、番号付きリスト、入れ子、明示した記号の保持を確認。メニュー表示への影響も確認。
- CKEditor 5 用 CSS のリスト表示を確認。
- CKEditor IndentBlock 1.1.0 の導入・有効化と、記事本文のエディターに段落インデントが読み込まれることを確認。
- 導入済みの設定と CSS を使ったブラウザー検証で、段落インデントの追加・解除と、HTML を再読み込みした際の保持を確認。記事本文の HTML フィルターがインデントのクラスを保持し、公開ページに表示用 CSS が追加されることも確認。
- 利用者による記事編集画面での動作確認が完了。
