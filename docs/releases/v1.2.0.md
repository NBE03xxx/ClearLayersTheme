# Clear Layers v1.2.0

[README に戻る](../../README.md)

この文書は v1.2.0 の変更を記録します。以下の旧バージョン・旧構成は、Clear Layers の v1.1.5以前を指します。新規利用者は [初期構成](../canvas-setup.md)、v1.1.5以前から更新する利用者は [更新手順](../upgrade-from-v1.1.5.md)を参照してください。

## 共通レイアウトと編集場所の整理

通常ページの外枠を「サイト共通レイアウト」（`site_layout`）1つに集約しました。v1.1.5以前の旧バージョンではヘッダー・フッターを別の共通パターンで編集していましたが、これからはページテンプレート上で内部の部品まで直接選択・編集できます。

- ヘッダー・ナビゲーション → Page content → フッターを共通レイアウトに配置します。
- 記事・固定ページは用途別の全文コンテンツテンプレート、Canvas ページは各ページの本文構成を使用します。
- 検索・タグ一覧の条件・件数・並び順は一覧側で管理します。タグ一覧のパネルは Views 用 Twig から SDC を利用して表示します。
- 新規初期構成は `site_layout` のみを作成します。旧共通パターンと分類専用の外枠は新規作成しません。
- 補助モジュールによる分類専用テンプレートの強制割り当てを廃止しました。フッターメニューブロックの初期値の調整は維持します。

## v1.1.5以前の旧バージョンを使用中のサイトへの適用

v1.1.5以前の旧バージョンを使用している場合は、テーマファイルの更新に加え、[更新手順](../upgrade-from-v1.1.5.md)を実行します。移行（変更前の自動バックアップを含む）→整理前の追加バックアップ→不要テンプレートの整理→検証→保管期間後のバックアップ削除の順に進めます。移行ツールはバックアップを作成し、保存済みの部品の入力値・UUID・親子関係を保持して共通パターンを展開します。未公開変更・翻訳・分類用テンプレートの独自配置など、自動移行できない状態では停止します。

v1.1.5以前の旧バージョンの `site_header` / `site_footer` パターンと参照用 SDC は、履歴などとの互換用に保持します。移行後の共通レイアウトとは同期しません。

v1.1.5以前の旧バージョン由来の自動生成テンプレート「Clear_layers theme」（`theme_clear_layers`）は、現在のページ・設定・翻訳・下書き・過去のリビジョンに参照がなければ削除できます。先に旧リージョンを無効化し、テーマ設定の保存による再生成を防ぎます。この整理は共通レイアウトの移行ツールとは別の操作です。

## 検証範囲

Drupal 11.4.11／Canvas 1.12.0 で、次を確認しました。

- 初期構成の schema、移行の再実行、既存本文・一覧設定・メニューの保持。
- Home・記事・固定ページ・検索・タグ一覧の HTTP 応答と、ヘッダー・フッターが各1つであること。
- 編集プレビューで、ヘッダー・フッター内部の部品にも選択用の情報があること。
- タグ一覧の見出し・パネルと、RSS に HTML の外枠が入らないこと。
- SDC・Twig の読み込みと Canvas のデータ整合性。
- 旧テンプレートの整理後も共通レイアウトと代表ページが正常であること。

ブラウザー上でのクリック・保存・公開操作と、画面幅ごとの目視確認は未実施です。実行コマンドと前提条件は [開発と検証](../development.md)を参照してください。
