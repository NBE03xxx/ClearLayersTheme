# Clear Layers v1.0.2

Drupal 11.4.9／Gin 5.0.15 の組み合わせで、通常の記事編集画面の Featured image やメディアグリッドのプレビュー枠が縦長になる問題に対する、Gin 用の補正 CSS を追加しました。

## 変更内容

- `css/gin-media-library.css` を追加。Claro の最小高さと Gin の余白が加算される問題を回避し、プレビュー枠を `aspect-ratio: 1` で正方形にします。
- migration.md に、Gin の `public://gin-custom.css` を使う配置手順を追加。
- README に、Core・Gin の更新後に補正なしで正常表示を確認できるまでは補正を維持する方針と、削除する前の確認方法を記載。

## 適用と更新後の扱い

補正は Clear Layers のフロント用ライブラリには含まれません。**テーマを更新するだけでは管理画面に適用されないため、症状が出ているサイトでは補正 CSS を `public://gin-custom.css` に追加してください。** 既存のカスタマイズを保持し、Core・Gin の配布ファイルは変更しません。

配置手順は [移行ガイド](https://github.com/NBE03xxx/ClearLayersTheme/blob/v1.0.2/docs/migration.md#gin-のメディアプレビューが縦長になる場合)、維持・削除の方針は [README](https://github.com/NBE03xxx/ClearLayersTheme/blob/v1.0.2/README.md#gin-のメディアプレビュー補正と更新時の扱い)を参照してください。Core・Gin の対応バージョンは未確認です。更新したという理由だけで補正を削除せず、検証環境で補正なしの表示を確認してください。

## 検証

- 記事編集画面とメディアグリッドの生成 HTML・適用 CSS を Chromium で検証。画面幅 1440・768・390px で、配置した補正によってプレビュー枠と画像が正方形になることを確認。
- 検証サイトへの配置、Gin による読み込み、CSS の配信、キャッシュ再構築を確認。利用者による正方形の表示確認も完了。
- 文書のローカルリンク・見出しリンク、バージョン表記、Git の差分を確認。
