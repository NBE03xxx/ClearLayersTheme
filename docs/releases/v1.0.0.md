# Clear Layers v1.0.0

Clear Layers の初回正式リリースです。Drupal 11 用の独立したテーマとして、半透明のパネル、柔らかなぼかし、重なりによる奥行きを備えています。

## 主な機能

- 配色、背景、透過率、ぼかし、奥行き、余白をテーマ設定から調整。
- OS 設定に連動する明暗モードと、訪問者による切り替え。
- Canvas で利用できる SDC と、サイト共通のヘッダー・フッターを参照する部品。
- 小さい画面で高さを抑えたヘッダーと、アイコンで開閉する検索パネル。
- テーマの配色と質感に合わせた公開操作パネル・ステータスメッセージ。
- 記事本文、カード、コードブロック、メニューの表示とキーボード操作への対応。
- 旧テーマからの移行スクリプトと移行手順。

## 利用方法

Drupal 11 と Twig Field Value / Twig Tweak が必要です。親テーマは不要です。Canvas は、Canvas で部品を編集する場合に別途導入してください。

ビルド済み CSS・JavaScript を含みます。GitHub のソース ZIP を利用する場合は、展開したフォルダーを `clear_layers` に変更し、`web/themes/custom/clear_layers` に配置してください。

詳細は [README](https://github.com/NBE03xxx/ClearLayersTheme/blob/v1.0.0/README.md) と [移行手順](https://github.com/NBE03xxx/ClearLayersTheme/blob/v1.0.0/docs/migration.md) を参照してください。

## 検証

Drupal 11.4.9 / Canvas 1.12.0 の環境で、42 個の SDC と 105 個の Drupal Twig テンプレートの読み込み、明暗モード、メニューのレンダリング、Canvas データの整合性を確認しました。旧テーマのアンインストール・削除後も、新テーマの動作とブラウザー表示を確認済みです。
