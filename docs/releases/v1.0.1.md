# Clear Layers v1.0.1

iPhone などの小さな画面で、検索パネルの展開時に表示がずれる問題を改善しました。

Byte・Mercury などの Canvas 対応テーマからの移行ガイドを、生成AIの活用を前提とした内容へ改訂しました。廃止済みの Liquid Glass 専用移行スクリプトも削除しました。今回の整理では、テーマの表示に関わるソースとバージョンは変更していません。

## 変更内容

- 小さな画面では検索パネルを右寄せ・最大 17.5rem（標準で 280px）にし、ヘッダーの幅に合わせて縮小。
- パネルの内側の余白を縮小。
- 検索入力欄の文字を 16px 以上にし、iPhone で入力時の自動拡大を抑制。
- 移行ガイドに、SSH と Codex CLI の作業環境、AGENTS.md、調査・移行・検証・不要ファイルの整理を依頼するプロンプト例を追加。
- 手動による移行手順を、ガイド後半の参考資料として整理。
- README の冒頭に、生成AIを活用する移行方針と、作業前に移行ガイドを読む案内を追加。
- 現在の移行ガイドでは使用しない、廃止済みの Liquid Glass 専用移行スクリプトを削除。
- タグに対応したリリースノートを公開・更新する GitHub Actions の処理を整備。

移行を始める前に、[README](https://github.com/NBE03xxx/ClearLayersTheme/blob/v1.0.1/README.md) と [移行ガイド](https://github.com/NBE03xxx/ClearLayersTheme/blob/v1.0.1/docs/migration.md) を確認してください。環境に合わせて調整する一例として記載しています。

## 検証

SCSS の構文確認と Drupal のキャッシュ再構築を実施し、利用者による iPhone での表示確認が完了しています。

今回の文書改訂では、文書内のローカルリンク・スクリプトのパス・SDC 名・コマンド例の構文と Git の差分を確認しました。ガイドに記載した移行・インストールコマンドは実行していません。

削除したスクリプトへの参照が現在のコード・利用手順に残っていないことも確認しました。
