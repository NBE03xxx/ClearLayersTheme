# Clear Layers v1.1.4

Canvas Library の Components タブで、配置できる部品が0件のフォルダーを非表示にする補助モジュール Canvas Library Display を同梱しました。テーマ設定の初期構成ボタンから、分類ページ用の補助モジュールと一緒に有効化できます。

## 変更内容

- `starter-kit/modules/canvas_library_display` を追加。Canvas が表示する部品数に従って0件のフォルダーを非表示にし、部品が増えると再表示します。名前を編集中の新規フォルダーは表示を維持します。
- フォルダーやコンポーネントの登録データは削除せず、Components タブの見え方だけを調整します。スクリプトは Canvas の編集画面で読み込みます。
- 「Canvas の初期構成を作成」ボタンから、Clear Layers Canvas Taxonomy と Canvas Library Display を有効化するようにしました。既存の同名パターン・テンプレートは保持します。
- 同梱モジュールの検出と、初期構成ボタンの送信処理の検証を更新しました。導入手順と、テーマ外にある同名モジュールからの切り替え方法も追記しました。

## 更新方法

テーマのファイルを更新し、Drupal プロジェクト直下で実行してください。

```sh
vendor/bin/drush cr
```

既存サイトでは、テーマの更新だけで未有効の補助モジュールを有効化しません。Library の表示調整を使う場合は、次のコマンドで有効化してから Canvas の画面を再読み込みしてください。

```sh
vendor/bin/drush en canvas_library_display -y
vendor/bin/drush cr
```

すでに同モジュールが有効な場合は、テーマ更新後のキャッシュ再構築と Canvas の再読み込みで反映します。`web/modules/custom/canvas_library_display` などテーマ外にも同名モジュールがある場合は、先にそのディレクトリをサイト外へ退避して同梱版だけにしてください。有効化済みモジュールのアンインストールは不要です。

新規サイトでは、[Canvas 初期構成の手順](../canvas-setup.md)に従ってテーマ設定のボタンを実行すると、補助モジュールも有効になります。初期構成済みのサイトでも、未公開の変更や検証エラーを整理してから再実行できます。表示調整だけを追加する場合は上記のコマンドを利用でき、初期構成の再実行は不要です。テーマのみを利用し、Canvas を使わないサイトでは有効化不要です。

テーマの再インストールや設定の一括インポートは不要です。表示調整は Canvas 1.12 の DOM を対象とし、Canvas の更新時にはセレクターの互換性を確認してください。

## 検証

- 初期構成で生成する４件のパターン・テンプレートの Canvas 検証、２つの同梱補助モジュールの検出、分類ページの割り当てとアクセス制御を確認しました。保存済み設定は変更していません。
- 変更した PHP の構文と、同梱 JavaScript の構文を確認しました。
- SDC 定義・Drupal Twig テンプレートの読み込みを確認しました。
