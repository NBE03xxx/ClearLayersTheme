# Clear Layers v1.2.1

[README に戻る](../../README.md)

## 配色に連動する文字選択色

紹介文・記事本文・コードブロックで、ドラッグした範囲の背景と文字色がテーマの配色・明暗モードに連動するようになりました。青系の背景やコードブロックでも、選択範囲を見分けやすくします。

- ライト表示では濃いアクセント色の背景と明るい文字、ダーク表示では明るいアクセント色の背景と暗い文字を組み合わせます。
- 選択背景を不透明にし、選択中の文字の影を取り除いて、半透明パネルでも文字を読みやすくします。
- OS の強制配色モードでは、システムの選択背景色・文字色を使用します。
- 投稿カード全体のリンク動作は従来どおりです。

## v1.2.0 からの更新

テーマディレクトリで `git pull --ff-only origin main` を実行し、Drupal プロジェクト直下で `vendor/bin/drush cr` によりキャッシュを再構築してください。設定変更・コンテンツ移行・依存パッケージの追加は不要です。

v1.1.5以前から更新する場合は、先に [更新専用の手順](../upgrade-from-v1.1.5.md)を確認してください。

## 検証範囲

- Chromium で12配色のライト・ダーク、計24パターンを確認。
- 紹介文・記事本文・コードブロックを実際にドラッグして選択できることを確認。
- 選択中の文字と背景のコントラスト比は全パターンで 5.54:1 以上。
- OS の強制配色モードでコードブロックの文字選択を確認。
- キャッシュ再構築後の実サイトで、追加 CSS の注入なしに選択色が適用されることを確認。
