# Clear Layers v1.1.3

標準サイトロゴを青・緑・赤・琥珀色・モノクロの５色から選べるようにしました。初期値では同梱の背景画像に合わせて自動選択し、テーマ設定から色を固定することもできます。テーマ一覧の紹介画像は、青を最前面に５色の背景を重ねた構図に更新しました。

## 変更内容

- 元のロゴと同じ形・透過背景・基準サイズを持つ５色の SVG を同梱しました。
- テーマ設定の「サイトロゴ」に「標準ロゴの色」を追加。背景画像に合わせた自動選択と５色の手動選択ができ、各色を明るい背景・暗い背景で確認できます。
- 標準ロゴの選択は、Drupal と Canvas のサイトブランディングブロックに共通で適用します。ダークモードではロゴを明るく調整し、OS 設定と訪問者の表示切り替えに連動します。
- 背景・ロゴの設定を変更した際に、キャッシュされたブランディング表示も更新されるようにしました。独自ロゴの設定と、ブロック側のロゴ表示・非表示を尊重します。
- テーマ一覧と README の紹介画像を更新し、５色の選択肢を示すようにしました。設定・更新・検証のガイドも更新しました。

## 更新方法

テーマのファイルを更新し、Drupal プロジェクト直下で実行してください。

```sh
vendor/bin/drush cr
```

テーマの再インストールや設定の一括インポートは不要です。標準ロゴを使用している既存サイトでは、色の設定が未保存でも背景画像に合わせた自動選択を使います。

色を固定する場合は、`/admin/appearance/settings/clear_layers` の「サイトロゴ」で「テーマ標準のロゴを使用する」をオンにし、「標準ロゴの色」を選択して保存してください。独自ロゴを使用しているサイトでは、標準ロゴを有効にするまでその画像を維持します。新規インストールでは、標準ロゴと自動選択を有効にします。

自動選択は同梱の５色の背景に対応します。テーマ標準の背景、見つからない背景、独自に追加した背景、以前のメディア背景では青を使います。必要に応じて手動で色を指定してください。「ロゴ・サイト名（手入力）」SDC に直接指定した画像 URL は維持します。

## 検証

- PHP 構文、５色の SVG の XML と基準サイズ、42件の SDC と105件の Drupal Twig テンプレートの読み込みを確認しました。
- 自動選択、５色×５背景の手動選択、独自ロゴの優先、ロゴ非表示、設定フォームの見本と schema、Drupal・Canvas の編集／公開表示とキャッシュ依存を確認しました。
- 同梱背景の選択・リセット・保存前のプレビューと、未保存のロゴ色の保持を確認しました。
- 明暗モードの切り替え処理、実際の Home のロゴ、外観画面の新しい紹介画像を確認しました。検証時に保存済みのテーマ設定が変わっていないことも確認しました。
- 利用者による実環境でのロゴと紹介画像の表示確認が完了しました。
