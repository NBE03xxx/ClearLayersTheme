# 案内ページコンポーネントの使い方

[README に戻る](../README.md#canvas-とページレイアウト)

「案内ページ」は、リンク集・サイトの利用案内・サイト方針などを、見出しと本文を持つ読みやすいパネルとして表示する Clear Layers 独自のコンポーネントです。半透明の背景、角丸、余白はテーマ設定に連動します。

コンポーネント ID は `clear_layers:information-page` です。「案内ページ」という名前のコンテンツタイプや URL を作る機能ではありません。テーマのインストールや Canvas 初期構成ボタンだけでは、案内ページや、それを使うコンテンツテンプレートは作成されません。

## Canvas ページに配置する

Canvas と Clear Layers を導入した状態で操作します。共通ヘッダー・フッターも用意する場合は、先に [Canvas 初期構成](canvas-setup.md)を行ってください。

1. Canvas で新しいページを作るか、編集したいページを開きます。
2. 部品ライブラリ（Library）から「案内ページ」を、ページ固有の本文領域に配置します。「サイト共通レイアウト」を使う場合は Page content の中です。
3. 「案内ページ」を選択し、**「本文幅」**を指定します。初期値は **75%** です。
4. **「ページの見出し」**に「見出し」（`clear_layers:content-heading`）を配置し、タイトルを入力します。ページの主見出しにする場合は Heading level を **1** にします。
5. **「本文」**に「本文（リッチテキスト）」（`clear_layers:content-text`）を配置し、文章やリンクを入力します。Text size は **normal**、Text color は **default** を基本にします。必要に応じて本文側に見出しや本文の部品を追加できます。
6. 保存・公開し、PC とスマートフォンの幅で表示を確認します。

ライブラリに部品が出ない場合は、管理者が「コンポーネントの状態」（`/admin/appearance/component/status`）で対象を有効にします。「案内ページ」「見出し」「本文（リッチテキスト）」をそれぞれ確認してください。

| 設定・配置先 | 用途 |
| --- | --- |
| 本文幅：75% | 広い画面で親の配置領域の75%幅にし、中央に配置します。文章を読むページ向けです。 |
| 本文幅：100% | 親の配置領域の幅を使います。ページ全体の左右余白はテーマ設定に従います。 |
| ページの見出し（`header_slot`） | タイトルなどを配置します。本文との間に区切り線が表示されます。 |
| 本文（`main_slot`） | 本文や見出しなどを配置します。本文は「本文（リッチテキスト）」で表示します。 |

75% の指定は画面幅が48rem以上の場合に適用されます。狭い画面では75%に縮めず、利用できる幅を使います。枠の色・透過・ぼかし・角丸・奥行きは、サイト共通のテーマ設定を使い、この部品で個別には指定しません。

## 通常の Drupal コンテンツを表示する場合

コンテンツのタイトルと本文を通常の Drupal コンテンツとして保存し、表示だけを「案内ページ」で構成することもできます。

1. 対象のコンテンツタイプと、書式付きの本文フィールドを用意します。
2. Canvas の **Templates → Content types** で対象のコンテンツタイプ・表示モードのコンテンツテンプレートを作成または編集します。
3. テンプレート内に「案内ページ」を配置します。
4. 「ページの見出し」に「見出し」を置き、Heading の入力元にコンテンツのタイトルを割り当てます。
5. 「本文」に「本文（リッチテキスト）」を置き、Rich text の入力元に本文フィールドの**処理済み HTML**を割り当てます。
6. 対象コンテンツをプレビューして、テンプレートの変更を公開します。

本文は通常のコンテンツ編集画面で編集し、配置・幅などはテンプレートで編集します。コンテンツテンプレートは、そのコンテンツタイプと表示モードに共通で適用されます。特定のページだけを作りたい場合は、前項の Canvas ページへの配置方法を使ってください。

## 目次・カード状リスト・補足文を使う

通常の箇条書きは通常のリストとして表示されます。下記の装飾は、本文の HTML に専用のクラスを付けた場合にだけ適用されます。目次やリンクの説明文を自動生成する機能はありません。

**Canvas 1.12 の標準のリッチテキスト入力は、固定された HTML 形式を使います。** `class`、見出しの `id`、下記の構造は標準入力で保持できません。固定形式 `canvas_html_block`／`canvas_html_inline` は管理画面から変更できません。以下は、前項のコンテンツテンプレートで、必要な HTML を保持できる本文フィールドを参照する場合の使い方です。

### 本文のエディターを準備する

管理者が「テキストフォーマットとエディター」（`/admin/config/content/formats`）で、**通常の本文フィールドに使うテキスト形式**を編集します。CKEditor 5 で HTML を入力する場合は、ツールバーに「ソース」（Source editing）を配置します。

通常の段落・リンク・リスト・見出しは対応するツールバーボタンで有効にし、ソース編集の「手動で編集可能な HTML タグ」には、必要な未対応の属性・要素を追加します。例は次のとおりです。

```html
<ul class="lg-resource-list">
<div class="lg-info-toc">
<p class="lg-info-note">
<h2 id>
<h3 id>
```

既に他のエディタープラグインが提供している属性・要素は重複登録せず、そのプラグインの設定に従います。HTML を制限するフィルターでも、使用する `class`・`id` と、通常の `<p>`・`<a href>`・`<ul>`・`<li>` などが許可されていることを確認してください。設定はテーマの導入では自動変更されません。

カード内に説明の段落を入れる場合は、CKEditor 5 のリスト設定で「リスト項目内に段落（または他のブロック要素）を作成できる」設定も有効にします。

本文のソース編集で、以下のうち使いたい部分を入力します。保存後に編集画面を開き直し、クラスや ID が保持され、公開ページでも反映されることを確認してください。

### カード状のリンク集

```html
<h2 id="resources">参考サイト</h2>
<ul class="lg-resource-list">
  <li>
    <a href="https://example.com/">参考サイト A</a>
    <p>このサイトで調べられる内容を説明します。</p>
  </li>
  <li>
    <a href="https://example.org/">参考サイト B</a>
    <p>リンクを開く前に分かると便利な情報を添えます。</p>
  </li>
</ul>
```

リストごとに `lg-resource-list` を付けます。付けていないリストは通常の表示のままです。各項目に余白・枠線・角丸・背景が付き、画面幅が48rem以上では2列、狭い画面では1列に並びます。クリックできるのはリンク文字部分です。

このカード表示は、**「案内ページ」内の「本文（リッチテキスト）」に表示したリスト**で利用します。クラスだけを他のページの本文に付けても、同じ表示にはなりません。

### 手動の目次

```html
<div class="lg-info-toc">
  <p>このページの内容</p>
  <ul>
    <li><a href="#resources">参考サイト</a></li>
    <li><a href="#contact">お問い合わせ</a></li>
  </ul>
</div>

<h2 id="resources">参考サイト</h2>
<p>参考サイトを紹介します。</p>

<h2 id="contact">お問い合わせ</h2>
<p>お問い合わせの方法を案内します。</p>
```

`lg-info-toc` を付けると、目次用の枠と背景が付きます。`href="#resources"` と `id="resources"` のように、リンク先と見出しの ID を一致させます。ID は同じページ内で重複させないでください。見出しを追加・変更したら目次も手動で更新します。

### 補足文

```html
<p class="lg-info-note">掲載情報は更新される場合があります。</p>
```

`lg-info-note` を付けた文章は、少し小さく、控えめな文字色で表示されます。

## 表示を確認する

- カードにならない場合は、「案内ページ」内に「本文（リッチテキスト）」を配置しているか、リスト本体に `lg-resource-list` があるかを確認します。
- クラスや ID が消える場合は、本文フィールドのテキスト形式とエディターの設定を確認します。Canvas 標準の固定形式への直接入力では、上記の装飾は利用できません。
- 目次から移動できない場合は、リンク先と見出しの ID が一致しているかを確認します。

HTML のリスト・リンク・段落自体は通常の構造ですが、専用クラスの装飾は Clear Layers に依存します。テーマを変更する場合は、案内ページを使う Canvas の構成と専用クラスの表示を確認してください。
