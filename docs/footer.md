# 共通フッターとメニューの使い方

[README に戻る](../README.md#canvas-とページレイアウト)

Clear Layers のフッターは、配置を担当する「フッター（レイアウト）」と、メニュー表示を担当する部品を組み合わせて作ります。「サイト共通レイアウト」に配置すると、そのレイアウトを使うページ全体に同じフッターを表示できます。

## 共通フッターを開く

[Canvas 初期構成](canvas-setup.md)で、ヘッダー・Page content・フッターを含む「サイト共通レイアウト」が作成されます。

1. Canvas の「Templates → Page templates → サイト共通レイアウト」を開きます。直接開く場合は `/canvas/editor/page_variant/site_layout` です。
2. 「フッター（レイアウト）」を選択し、必要な枠に部品を配置します。内側のメニューなども同じ画面で編集できます。
3. 保存・公開します。このレイアウトを使うページに変更が反映されます。ヘッダー・ナビゲーションも同じ画面で編集します。

初期構成を使わない場合も、このページテンプレートに「フッター（レイアウト）」を直接配置してください。`Page content` の後にフッターを1つ置く構成にします。

### v1.1.5以前の旧バージョンを使用している場合

v1.1.5以前の旧バージョンで「サイト共通ヘッダー・フッター」参照や `site_header` / `site_footer` パターンを使用している場合は、[更新手順](upgrade-from-v1.1.5.md)を先に実行してください。移行後は共通レイアウトが編集元となり、以前のパターンとは同期しません。不要な「Clear_layers theme」の整理とバックアップ削除も同じ手順に含まれます。

## フッターの枠に配置する

「フッター（レイアウト）」の ID は `clear_layers:site-footer` です。

| 配置先 | 用途の例 |
| --- | --- |
| 上段（1列） | ロゴ、サイトの説明 |
| 中段・左列 | フッターメニュー |
| 中段・中央列 | 分類・タグの一覧 |
| 中段・右列 | ログイン・ログアウトメニュー |
| 下段（1列） | 著作権表示、補足文 |

各枠に表示する部品を配置し、枠ごとに「左・中央・右」の表示位置を設定できます。上段・中段・下段の空の行は公開時に非表示になります。スマートフォンでは中段が左列・中央列・右列の順に縦に並びます。

「タグ：1行あたりの最大要素数」は1〜12、初期値は8です。タグ一覧を置いた枠が狭い場合は、文字が読める幅を保つため実際の列数を減らします。分類や Views の一覧は利用者が用意してから配置します。

## メニューとタイトルを設定する

1. Drupal のメニュー管理（`/admin/structure/menu`）で、表示するメニュー項目を用意します。標準のフッターメニューは `/admin/structure/menu/manage/footer` です。
2. フッターの枠に **「フッターメニュー（タイトル設定）」**（`clear_layers:footer-menu`）を配置します。
3. 内側の **「フッターメニュー」** に、標準のメニューブロック「フッター」を配置します。
4. 内側のブロックで開始階層・表示階層を設定し、外側の部品でタイトルを設定します。

| 外側の設定 | 動作 |
| --- | --- |
| タイトルの上書き | 空欄なら内側のフッターメニューブロックのタイトルを使用します。 |
| タイトルを表示 | 初期値はオフです。オンにするとタイトルを表示します。 |
| タイトルの表示位置 | 左・中央・右から選びます。初期値は左です。 |

他のメニューも、同じ部品の内側に標準メニューブロックを配置して表示できます。標準ブロック自体のタイトル設定は Canvas では省略されるため、外側で指定します。別のメニューのタイトルを表示する場合は、必要に応じて「タイトルの上書き」に入力してください。

### メニューの階層と追加時のエラー

初期構成で作るフッターメニューの開始階層・表示階層は、ともに **1** です。同梱の Clear Layers Canvas Taxonomy が有効なサイトで、新しく追加する標準「フッター」ブロックにも同じ初期値を使います。既存の配置の設定や、他のメニュー名のブロックの設定は変更しません。

標準メニューブロックの追加時に `Add a CSS class to ancestors of the current page` のエラーが出る場合は、内側のブロックで開始階層・表示階層をともに `1` にするか、そのチェック項目を有効にしてください。

ヘッダー専用の「サイトナビゲーション」は、開始階層1・表示階層0（無制限）・全項目展開で描画します。メニューブロックの階層フォームを通さないため、上記のフォーム検証の対象にはなりません。標準メニューブロックでの内部値 `null` も無制限を意味しますが、フッターの新規初期値には1を使います。

### 編集時に親部品を選択する

Canvas のプレビューでは、内側のメニューが入っていても外側の部品を選択できるよう、「フッターメニュー（タイトル設定）」の帯と余白を表示します。帯をクリックするか、左のレイヤー一覧から親部品を選択してタイトルを編集してください。編集用の帯と余白は公開ページには表示されません。

共通レイアウトのプレビューでは、ヘッダーからフッターまで確認しながら部品を選択・編集できます。

## ログイン・ログアウトを表示する

共通フッターの枠に **「ログイン・ログアウトメニュー」**（`clear_layers:account-menu`）を配置します。初期構成では中段・右列に配置済みです。この部品を「フッターメニュー（タイトル設定）」で包む必要はありません。

- 匿名の訪問者にはログイン、ログイン中の訪問者にはログアウトを表示します。
- タイトルの上書き・表示・位置を設定できます。
- 「ユーザーアカウント情報を表示」は初期状態でオフです。オンにすると、アクセス権のある利用者にアカウント情報へのリンクも表示します。

Drupal 標準のアクセス制御とログアウトのトークンを使用します。設定はこの部品の配置だけに適用され、サイトのメニュー設定は変更しません。専用部品なので、標準メニューブロックの階層フォームも使用しません。
